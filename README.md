# 🧪 Python Quest · Лаборатория данных

Игровой офлайн-курс для тех, кто переходит в дата-аналитику — в первую очередь для бывших ИТ-рекрутеров. Цель — не «пройти уроки», а уметь применять тему в реальной работе и объяснить её на собеседовании на позицию дата-аналитика.

Ты находишься в лаборатории данных: на стене висит воронка найма, а твой Python-код (он реально выполняется в браузере) раскладывает карточки кандидатов по этапам. За решённые задачи начисляется XP, прогресс сохраняется в браузере (localStorage).

## Как запустить

1. Скачай репозиторий (Code → Download ZIP) или `git clone`.
2. Открой `index.html` в браузере (Chrome, Edge, Firefox). Интернет не нужен.
3. Важно: папка `vendor/` должна лежать рядом с `index.html` — в ней Python-движок Brython.

## Структура урока

Каждый урок проходит одни и те же шаги:

1. **Понять** — объяснение с аналогией и визуализацией на стене лаборатории (до любых задач).
2. **Пример** — разобранный код с пояснением каждой строки.
3. **Тренировки** (2–3) — стартовый код с `???`, автопроверки через `assert`, понятные сообщения об ошибках и подсказки. Готового ответа в задании нет.
4. **Сделай сам** — тикет от коллеги: только условие и автопроверки, без заготовки решения.
5. **В работе** — где тема встречается в скриптах, pandas, SQL и DWH/ETL.
6. **Собеседование** — типовые вопросы; образец ответа открывается только после твоей попытки.

Урок считается **освоенным**, только когда решён «Сделай сам», написано объяснение выбора решения и дан ответ на вопрос собеседования.

## Как добавить урок

Контент хранится в массиве `LESSONS` внутри `index.html`. Скопируй объект урока 1, поменяй `id`, `title`, шаги (`steps`) и сними `locked: true`. Шаг-задача описывается полями `title`, `prompt`, `starter`, `checks` (пары `[assert-код, сообщение на русском]`), `hints`, `exports` (какие переменные передать в «мир» лаборатории).
